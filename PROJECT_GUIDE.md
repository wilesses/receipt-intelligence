# Receipt Tracker v2: памятка

Этот проект собирает чеки, достает из PDF товары, сохраняет их в SQLite-базу и показывает расходы через веб-интерфейс.

## Что где лежит

- `run.py` - запуск веб-приложения.
- `data/receipts.db` - основная база с чеками и товарами.
- `data/uploads/` - загруженные PDF-чеки.
- `app/web/routes.py` - страницы сайта и API для аналитики.
- `app/web/templates/` - HTML-страницы.
- `app/db.py` - работа с базой данных.
- `app/importer.py` - обработка PDF и сохранение чеков.
- `app/receipt_parser.py` - парсер текста чека.
- `app/category_keywords.py` - правила категорий товаров.
- `app/gmail_fetcher.py` - загрузка чеков из Gmail через настройки `.env`.
- `refactor_preview/` - безопасная улучшенная копия части проекта, оригинал она не заменяет.

## Как запустить проект

Открой PowerShell в папке проекта:

```powershell
cd "D:\Python projects\reciept_tracker_v2"
```

Активируй виртуальное окружение:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установи зависимости:

```powershell
pip install -r requirements.txt
```

Запусти приложение:

```powershell
python run.py
```

Открой в браузере:

```text
http://127.0.0.1:5000
```

## Основные страницы

- `http://127.0.0.1:5000/` - список чеков.
- `http://127.0.0.1:5000/upload` - загрузка PDF-чеков и проверка Gmail.
- `http://127.0.0.1:5000/analytics` - аналитика расходов.

## Как остановить приложение

В окне PowerShell, где запущен сервер, нажми:

```text
Ctrl+C
```

- Не удаляй `data/receipts.db`, если хочешь сохранить историю чеков.
- Не публикуй `.env`, там могут быть данные для входа в почту.
- Если внешний вид в браузере не обновился, нажми `Ctrl+F5`.

## Почему некоторые PDF не импортируются

Есть два типа чеков:

- PDF с текстовым слоем - такие читает `pdfplumber`, пример: чеки Maxima.
- PDF-скан/картинка - внутри нет текста, только изображение страницы. Такие чеки требуют OCR, пример: некоторые чеки Rimi.

Проект теперь умеет распознавать эту ситуацию и покажет понятную ошибку. Для автоматического чтения сканов нужно установить Tesseract OCR и добавить команду `tesseract` в `PATH`. Для латышских чеков желательно установить языковой пакет `lav`.

## Gmail импорт

На странице `/upload` есть кнопка `Проверить почту`. Она:

- подключается к Gmail по настройкам из `.env`;
- ищет письма за последние `DAYS_LOOKBACK` дней;
- скачивает PDF-вложения;
- сразу запускает импорт чеков в базу.

Полезные настройки в `.env`:

- `IMAP_SERVER` - обычно `imap.gmail.com`;
- `EMAIL_ACCOUNT` - Gmail-адрес;
- `APP_PASSWORD` - пароль приложения Gmail;
- `SAVE_FOLDER` - папка для скачанных PDF, сейчас `data/pdf_receipts`;
- `DAYS_LOOKBACK` - сколько дней назад проверять;
- `GMAIL_MAX_EMAILS` - максимум писем за одну проверку, по умолчанию `100`;
- `GMAIL_SENDERS` - необязательный список отправителей через запятую. Если не задан, используется Maxima.

Не публикуй `.env`: там секреты.
